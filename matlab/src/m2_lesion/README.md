# Learned lesion module (opt-in; Python-first research module)
`segmentLesionsLearned.m` runs the exported lesion segmenter (`lesion_unet_b2_1024.onnx`, U-Net with an EfficientNet-B2 encoder, fixed 1x3x1024x1024 input; export and fixtures: `python/lesion_matlab_fixtures.py`) over a work image (field-cropped, long side <= 1536) with the same 1024/128 windowing and per-window Ben Graham enhancement as the Python reference. It does **not** change `main_pipeline.m`.
Verified by `matlab/verifyLesionLearned.m` on three validation images (2026-10-22): network parity on identical input <= 7.4e-6 in probability; the MATLAB Ben Graham enhancement differs from OpenCV by up to 4 grey levels on 0.5-0.8% of pixels (blur rounding); end-to-end mean abs probability difference <= 9e-6, isolated pixel maxima 0.02-0.19, frozen-threshold mask disagreement <= 2.5e-6 of pixels. The O3 tolerance on the end-to-end *maximum* (1e-3) is NOT met (isolated pixels); the mask tolerance (0.1% of pixels) is met. The fixed-size ONNX input zero-pads partial windows to 1024 (differs from the 32-multiple padding of the Python production path by mean 1e-4, mask disagreement ~3e-5).
Native-resolution validation of the Python model and the locked DDR result: `.project-notes/experiments/X8/`.
