# mBRSET fresh test (tier TF) — single locked evaluation, 2026-10-23

mBRSET 1.0 (PhysioNet credentialed; Phelcom Eyer smartphone camera, Brazil). `lock.json` (40 bound artifacts, `labels_read: false`) preceded the one
evaluation `report.json`. Primary: referable DR (ICDR >= 2), 4,859 gradable graded images (861 referable), 1,285 patient clusters, 2,000 bootstrap
replicates. 292 images ungradable (`final_quality` = no) and 13 gradable images without an ICDR grade are outside the DR metrics (counted, listed).
Images are not redistributed (DUA). Pre-registration: MODEL_IMPROVEMENT_PLAN_v5 Addenda 2, 3, 3a (private notes); decision record O8_REVIEW.md.
The curated `report.json` omits two lists of image file names (13 graded-less images; none without a label row); the full report stays with the lock
under `results/model_improvement/mbrset_lock/`. Cite: Nakayama LF et al., mBRSET (v1.0), PhysioNet 2024, doi:10.13026/qxpd-1y65; Pollard T et al.,
Nature Health 2026, doi:10.1038/s44360-026-00096-z.
