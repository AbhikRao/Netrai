BRSET (PhysioNet, credentialed; three São Paulo centres 2010–2020; Canon CR and Nikon NF5050 desktop cameras). `lock.json` (34 bound artifacts, `labels_read: false`) preceded the one
evaluation `report.json` (curated copy: file-name lists omitted). Primary: referable DR (`DR_ICDR` >= 2), 14,280 images with adequate quality and a grade (841 referable), 8,070 patients,
