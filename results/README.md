# Evaluation evidence

Dated directories preserve the model, dataset and workflow context of each
experiment. Historical results remain available even when later audits change
how they can be interpreted. Do not combine numbers from different runtime,
model, preprocessing or routing configurations into one performance claim.

Start with the [validation report](../docs/VALIDATION.md), which links the relevant
MATLAB grading, overlap, external-domain and capacity-simulation artifacts.
Image derivatives and generated patient reports are not included.
